# مساحتي | Masahati — إعادة بناء الواجهات

واجهة تجريبية HTML/CSS/JavaScript مستوحاة من صور التصميم التسع المقدمة. تشمل: الرئيسية، قائمة المساحات، تفاصيل المساحة، طلب الاستئجار، الاشتراكات، تسجيل الدخول، لوحة المالك، إدارة المساحات، إضافة مساحة، الطلبات، الإحصائيات والمفضلة.

## التشغيل
افتح `index.html` في المتصفح. لا يتطلب خادماً. قد يحتاج خط Cairo إلى اتصال بالإنترنت، مع وجود خط بديل عند عدم توفره.

## ملاحظات مهمة
- الصور المستخدمة في بطاقات العقارات مقتطعة من الصور المرجعية التي قدمها المستخدم، ولذلك قد تحتوي بعض القصاصات على عناصر واجهة أصلية.
- الأرقام والأسعار والعقارات بيانات توضيحية مأخوذة من تصميم الواجهة، وليست عروض عقارات حقيقية.
- الحفظ التجريبي يتم باستخدام localStorage. لا توجد قاعدة بيانات أو تسجيل دخول آمن أو دفع أو إرسال بريد فعلي.
- يهدف المشروع إلى محاكاة الشكل والتفاعلات الأمامية، وليس منصة إنتاجية مكتملة.
